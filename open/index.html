The App Clip didn't open

Safari loaded this page instead of the iDesign App Clip. While the clip is not published, a test iPhone opens it through a Local Experience:

  1. Install the clip on the phone from Xcode (scheme NativeScanClip).
  2. Settings → Developer → App Clips Testing → Local Experiences → Register: URL prefix , bundle ID com.framesixty.idesign.nativescan.Clip.
  3. If the full Cabinet Scan app opens instead, delete it from the phone.
  4. Scan the QR code on the home page with the Camera, or tap Start there again.
